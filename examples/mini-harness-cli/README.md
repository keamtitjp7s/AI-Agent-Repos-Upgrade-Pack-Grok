# mini-harness-cli

Pełna aplikacja CLI wygenerowana od podstaw przez **AI Agent Repos Upgrade Pack - Grok**.

## Idea źródłowa
Meta-harness for multiple coding agents (Claude Code, Codex, Cursor, Grok Build)

## Uruchomienie

```bash
node index.js list
node index.js run grok "upgrade all agent repos"
```

## Co robi
- Lista dostępnych agentów
- Symulacja uruchomienia wybranego agenta z zadaniem
- Wbudowane polityki (sandbox, cost-limit)

Gotowe do rozbudowy o realne wywołania CLI / MCP.
